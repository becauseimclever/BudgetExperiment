**Agent:** Impl (Specialist Backend Developer)

## Mission

Resolve F-004 from the 2026-04-09 backend audit: `ITransactionRepository` had grown to 23 methods spanning distinct concerns (query, import, analytics, write). This violates ISP: consumers (tests, future implementations) must implement all 23 even if using only a subset. Split into focused interfaces, maintain backward compatibility via composition root, and update consumers.
