## Mission

Resolve F-002 and F-003 from the 2026-04-09 backend audit: two controllers (`CalendarController`, `AccountsController`) were directly injecting concrete application service classes, violating the Dependency Inversion Principle (Decision #2, 2026-03-22). Extract interfaces, update DI, ensure build passes.

## Execution

### Phase 1: Extract ICalendarService

1. Inspected `CalendarController` — identified single call site: `_calendarService.GetMonthAsync(year, month, cancellationToken)`
2. Created `src/BudgetExperiment.Application/Calendar/ICalendarService.cs` with single method signature
3. Made `CalendarService` implement `ICalendarService` (added `: ICalendarService` to class declaration)
4. Updated `CalendarController` constructor: `ICalendarService calendarService` (replacing `CalendarService`)
5. Updated DI registration: `services.AddScoped<ICalendarService, CalendarService>()`
6. Build: ✅ 0 errors, 0 warnings

**Commit:** `7f7a3a6` — refactor(app): extract ICalendarService, update CalendarController to inject abstraction
